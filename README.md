# 🎓 AI-Powered Student Performance Predictor

## 📌 Project Overview

The AI-Powered Student Performance Predictor is a Machine Learning application that predicts a student's expected final score based on their study hours, previous exam score, and attendance percentage.

The project uses Python, Pandas, Scikit-learn, Linear Regression, and Streamlit.

## 🎯 Objective

The main objective of this project is to demonstrate how Machine Learning can be used to analyze student-related data and predict academic performance.

## 🚀 Features

* Enter hours studied
* Enter previous exam score
* Enter attendance percentage
* Predict expected final score
* Display performance feedback
* Simple and user-friendly interface

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Linear Regression
* Streamlit
* GitHub

## ⚙️ How to Run

### 1. Install the required libraries

```bash
pip install -r requirements.txt
```

### 2. Train the Machine Learning model

```bash
python train_model.py
```

### 3. Run the application

```bash
streamlit run app.py
```

## 🧠 Machine Learning Algorithm

This project uses **Linear Regression**.

The model learns the relationship between:

* Hours Studied
* Previous Score
* Attendance

and the student's:

* Final Score

## 📊 Example

Input:

* Hours Studied: 8
* Previous Score: 70
* Attendance: 85%

Output:

```text
Predicted Final Score: approximately 76%
```
